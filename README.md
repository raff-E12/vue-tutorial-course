# 📦 Progetti in Dispensa — Vue 3

Raccolta di progetti realizzati con **Vue 3**, con supporto a **Pinia**, **Vue Router** e, come bonus, **Bootstrap 5** integrato nativamente con Vue 3.

---

## 🚀 Stack Tecnologico

| Tool | Versione |
|------|----------|
| Vue | ^3.x |
| Pinia | ^2.x |
| Vue Router | ^4.x |
| Bootstrap *(plus)* | ^5.x |

---

## ⚙️ Installazione

```bash
# Clona il repository
git clone https://github.com/tuo-utente/nome-progetto.git
cd nome-progetto

# Installa le dipendenze
npm install

# Avvia il server di sviluppo
npm run dev
```

---

## ➕ Plus — Bootstrap con Vue 3

Bootstrap 5 è compatibile nativamente con Vue 3 **senza dipendenze extra** come `bootstrap-vue-next`. Nel Implementazione dei Progetti Vue in uso con Vite.

## 📜 Script disponibili

```bash
npm run dev      # sviluppo
npm run build    # produzione
npm run preview  # anteprima build
```
